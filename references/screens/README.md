# Reference screenshots (calibration)

Currently empty. Until someone adds screenshots, treat [~] values as estimates and say so if a client asks about pixel-accuracy.

Apps change their UI every few months. Kit values marked [~] in kit.css are estimates; [V] were matched to real screenshots.

Add real screenshots here as `<platform>-<os>-<surface>-<YYYY-MM>.png`, e.g. `line-ios-chat-light-2026-11.png`.
- Take them on a real device or from the platform's official ad preview, with your own/test accounts. No customer data.
- When you recalibrate a value in kit.css, change its marker to [V] and mention the screenshot file in a comment.
- Delete screenshots older than ~12 months once newer ones exist.
